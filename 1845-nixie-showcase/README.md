# 1845 Nixie Showcase

Отдельный standalone-концепт для Lounge Bar 1845, собранный с нуля по cinematic/Nixie арт-дирекшну.

## Особенности

- пять Nixie-ламп `18:45`, включая отдельную лампу `:`;
- случайное независимое мерцание каждой колбы;
- 3D-наклон с инерцией и внутренним параллаксом;
- полностью локальные HTML/CSS/JS без внешних зависимостей;
- адаптивность и `prefers-reduced-motion`.

GitHub Pages: `/1845/1845-nixie-showcase/`.
