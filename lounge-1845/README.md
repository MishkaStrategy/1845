# 1845 Lounge Bar

Адаптивный промо‑сайт цифровой экосистемы Lounge Bar 1845.

## Особенности

- CSS‑арт ламп ИН‑14 с мерцающими цифрами `18:45`
- фоновые искры, мягкий параллакс и интерактивный свет
- анимации появления, орбитальная схема решений и микроанимации кнопок
- адаптивная навигация и мобильная версия
- поддержка `prefers-reduced-motion`
- без сборщика и зависимостей

## Локальный запуск

Откройте `index.html` в браузере или запустите статический сервер:

```bash
python3 -m http.server 8080 --directory lounge-1845
```

## Публикация

Сайт публикуется через GitHub Pages workflow из папки `lounge-1845`.
