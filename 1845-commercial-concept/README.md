# 1845 — Digital Private Layer

Отдельный коммерческий digital-концепт для Lounge Bar 1845, созданный с нуля без использования визуальной системы существующего проекта в корне репозитория.

## Creative concept

**Digital Private Layer** — цифровое продолжение ощущения приватного комфортного пространства:

- Website = Entrance
- Telegram = Concierge
- App = Membership
- Network = Backstage

Основная формула: **«Город снаружи. 1845 — внутри.»**

## Research snapshot

Открытые источники проверены 25.08.2026. В концепте факты отделены от дизайнерских гипотез. Чужие интерьерные фотографии не используются и изображения картографических сервисов не hotlink-ятся.

## Runtime

Статический standalone HTML без внешних runtime-зависимостей — оптимально для GitHub Pages. Есть responsive layout, touch-safe interactions, semantic sections и `prefers-reduced-motion`.
